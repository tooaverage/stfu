# Security

Email hi@jayceeday.com to report a security issue in stfu. Please don't open a public issue for it.

Say what you found and how to repeat it. I'll reply within 7 days and tell you when it's fixed.

stfu runs nothing on its own. The skill is Markdown, and `check.py` only reads the files you name. See [What it runs](README.md#what-it-runs).
